# csv2vcf — แปลงรายชื่อผู้ติดต่อ CSV เป็น vCard (.vcf)

สคริปต์ Python ไฟล์เดียว (ใช้แค่ standard library ไม่ต้องติดตั้งอะไรเพิ่ม) สำหรับแปลงไฟล์รายชื่อ
`.csv` เป็นไฟล์ `.vcf` (vCard 3.0) เพื่อนำเข้า Android, iPhone, Google Contacts หรือ Outlook

ต้องใช้ Python 3.8 ขึ้นไป

## วิธีใช้

```bash
python3 csv2vcf.py contacts.csv                      # ได้ไฟล์ contacts.vcf
python3 csv2vcf.py contacts.csv -o phone.vcf         # ระบุชื่อไฟล์ผลลัพธ์
python3 csv2vcf.py contacts.csv --country-code 66    # 081-234-5678 -> +66 81-234-5678
python3 csv2vcf.py contacts.csv -o - > out.vcf       # เขียนออก stdout
```

ลองกับไฟล์ตัวอย่าง: `python3 csv2vcf.py examples/contacts.csv -o -`

| ตัวเลือก | ความหมาย |
| --- | --- |
| `-o, --output` | ไฟล์ผลลัพธ์ (ค่าเริ่มต้น: ชื่อเดียวกับไฟล์ CSV แต่เป็น `.vcf`, `-` = stdout) |
| `-e, --encoding` | encoding ของ CSV (ค่าเริ่มต้น `auto`: UTF-8/UTF-16 ที่มี BOM, UTF-8 แล้วจึงลอง `cp874` ภาษาไทย Windows) |
| `-d, --delimiter` | ตัวคั่นคอลัมน์ (`,` `;` `tab` `|`) ค่าเริ่มต้นตรวจจับอัตโนมัติ และรองรับบรรทัด `sep=;` ของ Excel |
| `--country-code` | แปลงเบอร์ที่ขึ้นต้นด้วย `0` เป็นรูปแบบสากล เช่น `66` |
| `--date-order` | อ่านวันเกิดแบบ `xx/xx/yyyy` เป็น `dmy` (ค่าเริ่มต้น) หรือ `mdy` |
| `--max-size` | ขนาด CSV สูงสุดเป็น MB (ค่าเริ่มต้น 50) |
| `-f, --force` | เขียนทับไฟล์ผลลัพธ์ที่มีอยู่แล้ว |
| `-q, --quiet` | ไม่แสดงคำเตือนรายแถว |

## คอลัมน์ที่รองรับ

แถวแรกของไฟล์ต้องเป็นหัวตาราง ชื่อคอลัมน์ไม่สนตัวพิมพ์เล็ก/ใหญ่ และรองรับไฟล์ export จาก
**Google Contacts** (`Phone 1 - Type`, `E-mail 1 - Value`, `Address 1 - City`, …) และ **Outlook**
(`Mobile Phone`, `Business Fax`, `E-mail 2 Address`, `Home Street`, …) ได้ทันที

| ข้อมูล | ตัวอย่างชื่อคอลัมน์ |
| --- | --- |
| ชื่อเต็ม | `Name`, `Full Name`, `ชื่อ-นามสกุล`, `ชื่อเต็ม` |
| ชื่อ / นามสกุล / ชื่อกลาง | `First Name`, `Last Name`, `Middle Name`, `ชื่อ`, `นามสกุล` |
| คำนำหน้า / ชื่อเล่น | `Prefix`, `Nickname`, `คำนำหน้า`, `ชื่อเล่น` |
| บริษัท / ตำแหน่ง / แผนก | `Company`, `Job Title`, `Department`, `บริษัท`, `ตำแหน่ง`, `แผนก` |
| เบอร์โทร | `Phone`, `Mobile`, `Home Phone`, `Work Phone`, `Fax`, `เบอร์โทร`, `มือถือ`, `เบอร์บ้าน`, `เบอร์ที่ทำงาน` |
| อีเมล | `Email`, `E-mail Address`, `Work Email`, `อีเมล` |
| ที่อยู่ | `Address`, `Street`, `City`, `State`, `Postal Code`, `Country`, `ที่อยู่`, `ตำบล/แขวง`, `อำเภอ/เขต`, `จังหวัด`, `รหัสไปรษณีย์` |
| เว็บไซต์ | `Website`, `URL`, `เว็บไซต์` |
| วันเกิด | `Birthday`, `วันเกิด` (`YYYY-MM-DD` หรือ `DD/MM/YYYY`, ปี พ.ศ. แปลงเป็น ค.ศ. ให้อัตโนมัติ) |
| หมายเหตุ | `Notes`, `หมายเหตุ` |

- ในช่องเดียวใส่ได้หลายเบอร์/หลายอีเมล คั่นด้วย `,` `;` `/` หรือ `:::` (แบบ Google)
- เบอร์ภายใน เช่น `02-123-4567 ต่อ 12` หรือ `ext 12` จะแปลงเป็น `02-123-4567,12` (โทรแล้วกดต่อให้อัตโนมัติ)
- เลขไทย (๐-๙) ในเบอร์โทรและวันเกิดจะแปลงเป็นเลขอารบิก
- คอลัมน์ที่ไม่รู้จักจะถูกข้ามและแจ้งชื่อให้ทราบ

> **เคล็ดลับ Excel:** ตั้งคอลัมน์เบอร์โทรเป็น *Text* ก่อน export ไม่เช่นนั้น Excel จะตัดเลข 0 นำหน้า
> หรือแปลงเป็นเลขวิทยาศาสตร์ (เช่น `8.12E+08`) ซึ่งโปรแกรมจะข้ามพร้อมแจ้งเตือน

## ความปลอดภัย

- **กัน vCard injection:** escape `\` `,` `;` และขึ้นบรรทัดใหม่ทุกรูปแบบ (CR, LF, U+2028, …) ตาม RFC 2426/6350
  ข้อมูลในเซลล์จึงสร้าง property ใหม่ (เช่น `END:VCARD`) ไม่ได้ ชนิดเบอร์ (`TYPE=`) มาจาก allowlist เท่านั้น
- ลบอักขระควบคุมและอักขระ bidi override ที่ใช้ปลอมชื่อผู้ติดต่อได้
- URL รับเฉพาะ `http`/`https` (ปฏิเสธ `javascript:`, `data:`, `file:` …) อีเมลและเบอร์โทรถูกตรวจรูปแบบ
- regex ทุกตัวทำงานแบบเชิงเส้น (ไม่มี ReDoS) และจำกัดขนาดไฟล์/ขนาดเซลล์
- ข้อความเตือนที่ยกค่าจากไฟล์ถูก escape ก่อนแสดง กัน ANSI escape sequence ควบคุม terminal
- เขียนไฟล์ผลลัพธ์ผ่านไฟล์ชั่วคราวแล้ว rename แบบ atomic สิทธิ์ `600` (ข้อมูลส่วนบุคคล)
  ไม่เขียนทับไฟล์เดิมถ้าไม่ใส่ `--force` และไม่ยอมเขียนทับไฟล์ CSV ต้นฉบับ (รวมถึงผ่าน symlink)
- CSV ที่เครื่องหมายคำพูดไม่ปิดจะถูกปฏิเสธ แทนที่จะรวมหลายแถวเป็นรายชื่อเดียวแบบเงียบ ๆ
